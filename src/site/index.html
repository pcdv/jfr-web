jfr-web

A web interface for JFR recordings: a timeline, flame graphs and tables per operation of the application (an HTTP request, a call of its own API), the history of its operations. Each demo is a static export of an application run for a few minutes: a session recorded for 10 seconds, and the history of the minutes after it.

An HTTP app

A flak app, whose requests are operations by themselves: sorting, listing files, writing and reading files.

A TCP server

An order server with a line protocol, which tells its operations through the jfrweb.ops API: synchronous quotes and reports, orders matched asynchronously by another thread.

Source, documentation and releases: github.com/pcdv/jfr-web
